Pomodoro Timer

シンプルなポモドーロタイマーアプリです。  
作業と休憩を管理し、進捗を視覚的に確認できます。

現在の状態

このアプリはMVP段階です。  
基本的なタイマー操作と、設定の保存に対応しています。

起動方法:
    pomodoro.exe をダブルクリック

必要なファイル:
    - pomodoro.exe
    - settings.json
    - fonts/
    - SDL2.dll
    - SDL2_ttf.dll
    - freetype.dll
    - z.dll
    - libpng16.dll
    - brotlidec.dll
    - brotlicommon.dll
    - brotlienc.dll
    - bz2.dll

注意:
    このフォルダ内のファイルは、一緒に移動してください。
    DLLやfontsフォルダを削除すると、起動しなくなる場合があります。
